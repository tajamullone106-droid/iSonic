### ✨ Features

- 🎵 YouTube se seedha voice chat me music stream
- 📃 Queue system — multiple songs add karo
- ⏯ Pause / Resume / Skip / End
- 🔁 Loop mode
- 👑 Admin-only controls
- 📊 Live stats (CPU, RAM, chats, users)
- 📢 Owner broadcast system
- 💌 Cute animated-style /start menu with inline buttons

### 🛠 Requirements

- VPS (Ubuntu 20.04/22.04 recommended)
- Python 3.10+
- FFmpeg
- MongoDB URI
- Telegram API_ID / API_HASH (my.telegram.org)
- Bot Token (@BotFather)
